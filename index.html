    Install CodeLearn

    Add CodeLearn to your home screen or desktop for an app-like experience. First open the site while connected so its lessons can be saved for offline use.

    • Android / Chrome: open the browser menu and tap Install app or Add to Home screen.
    • iPhone / iPad: in Safari, tap Share, then Add to Home Screen.
    • Desktop: use the install icon in the address bar, or choose Install CodeLearn from the browser menu.

    The site must be hosted on HTTPS (or opened through localhost) for installation and offline caching. Running Python examples still requires an internet connection the first time.
